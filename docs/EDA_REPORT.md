## Relative source-sequence timing

Relative deltas are calculated only in original row order and within each dataset. They are wall-clock differences, not absolute UTC durations. Unknown-year syslog entries never receive an assigned year; ambiguous leap-day crossings and non-chronological date changes are marked rather than guessed. Apache deltas remain timezone-naive.
