# Synthetic Detection Evaluation

Generated by `scripts/run_detection.py` from local synthetic data. Scenario labels are loaded from a separate annotation file only after detection completes.

## Evaluation method

- Unit: **scenario-level** (29 evaluation scenarios).
- A scenario is predicted suspicious if at least one security alert references an event assigned to that scenario. Operational-anomaly alerts are excluded from security metrics.
- Detector inputs contain normalized events only; scenario IDs and ground-truth labels are held in a separate annotation JSONL.
- Development events build the R06 baseline and are not included in evaluation metrics.
